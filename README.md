## 三个下单前必须知道的限制

### 1. 入门型不保障跨境公网质量

腾讯云文档注明，香港入门型套餐无法保障跨境（内地与香港之间）的公网质量，面向大陆用户建议选锐驰型或通用型。这条限制比参数表上任何一项都重要，但多数测评只贴延迟截图，不提这个前提。

如果你的读者、客户主要在大陆，别为省十几块钱选入门型。白天可能看不出差别，晚高峰的稳定性差距会直接体现在访问体验上。

### 2. 操作系统一次选定，Linux 和 Windows 不能互换

香港轻量选择操作系统后不支持 Linux 和 Windows 互换，选错只能重装或重新购买。同配置下 Windows 版本更贵，因为含版权费：测评文章记录的 2核2G/20M/40G 档，Linux 活动价 288 元/年、Windows 活动价 360 元/年。这两个数字是活动价，仅用于说明差价；当前价格以下单页为准。没有 Windows 刚需，选 Linux。

### 3. 流量包只算出流量，超了按 GB 收费

月流量包统计的是服务器出流量，超出部分按 GB 计费，不会停机，但账单会增加。入门型 512G 流量配 20Mbps 带宽，如果持续满速下载，大约两天多就能跑完（20Mbps 约合 2.5MB/s，512G 约合 51.2 万 MB）。正常网站访问远达不到这个量，视频站、软件下载站要提前算账。锐驰型是无限流量，做流量型业务更省心。

还有两条产品层面的限制会影响架构：轻量套餐只能升级不能降级；默认不支持自定义 VPC，与 CVM、云数据库等产品内网不互通，需要云联网。如果项目以后要和腾讯云其他产品组网，提前规划，别等业务上线才发现要换机型。

## 常见问题

**腾讯云香港轻量服务器需要备案吗？**
不需要。香港地域不在 ICP 备案范围内，域名解析过去就能上线，这是香港轻量搜索量一直很高的主要原因。

**20Mbps 带宽够用吗？**
个人博客、企业官网、小程序后端够用。20Mbps 约合 2.5MB/s，同时支撑几十个普通网页访客没问题。视频、大文件下载不够，选锐驰型的 200Mbps。

**香港轻量和国内轻量怎么选？**
看访客在哪。访客在大陆且能完成备案，国内地域延迟更低、同价位配置更高；不想备案或访客在境外，选香港。香港带宽成本更高，同样价格买不到国内那样的配置。

**能升级套餐吗？**
可以升级，不能降级。轻量是套餐制，计算、存储、网络整体升级。

**流量用超了会怎样？**
超出月流量包的部分按出流量 GB 计费，不会直接停机，但费用会增加。

**Linux 和 Windows 能互换吗？**
香港轻量不支持互换，下单前定好系统。
